# 🧠 Brain Tumor Detection using ML & Streamlit

An AI-powered web application that detects brain tumors from MRI images using a trained machine learning model. Built with an interactive UI using Streamlit for real-time predictions and visualization.

---

## 🚀 Features

* 🖼️ Upload MRI brain scan images
* 🤖 Predict Tumor / No Tumor
* 📊 Confidence score visualization
* ⚡ Fast & interactive Streamlit UI
* 🧪 Image preprocessing (resize, normalization)
* 🔍 Grayscale & edge detection preview
* 🎯 Adjustable confidence threshold

---

## 🛠️ Tech Stack

* Python
* Streamlit
* Scikit-learn / TensorFlow
* NumPy
* OpenCV
* Plotly

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/your-username/brain-tumor-detection.git
cd brain-tumor-detection
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run Application

```bash
streamlit run app.py
```

## 🧠 How It Works

1. Upload MRI image
2. Image preprocessing (resize & normalize)
3. Model prediction
4. Display result with confidence
5. Visual insights shown in charts
